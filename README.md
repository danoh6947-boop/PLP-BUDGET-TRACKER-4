# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application for organizing and displaying daily expenses.

The project was built using HTML and CSS.

## Features

### Add Expense Form

The form allows the user to enter:

* Expense name
* Amount
* Category

The category field contains Food, Transport, Rent, Entertainment, and Other.

### Expense Table

The expense table displays:

* Name
* Amount
* Category
* Date

It includes borders, spacing, alternating row colors, and a styled header.

### Visual Design

The application uses a consistent blue, white, and light-gray color palette.

### Typography

Google Fonts are used to improve readability:

* Merriweather is used for headings.
* DM Sans is used for body text, forms, buttons, and table content.

### CSS Box Model

The project uses:

* Margin for spacing between sections.
* Padding for space inside sections.
* Borders to define sections.
* Border-radius for rounded corners.

The page heading, Add Expense form, and Expense Table are displayed as separate cards.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
